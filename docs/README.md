# Research guide

This index covers the research notes in this directory. Start with the [master evidence assessment](master-feasibility-evidence.md) for the conclusions and evidence limits. The dated notes preserve the source audits and experimental details behind it. [Raw records and their status](../data/README.md) and [analysis scripts](../scripts/README.md) are indexed separately.

The model-efficiency work uses four joint checks: complete deployable bytes, peak CPU memory, CPU time for a complete request, and quality on frozen benign dependent-step tasks against a same-source Q4_K_M reference. A gain on one measure does not establish a joint result. The November 21 held-out reference run was interrupted and has no candidate arm. It is not a completed quality comparison.
