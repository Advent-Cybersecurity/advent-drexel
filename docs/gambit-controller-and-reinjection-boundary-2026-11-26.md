# External agent control and deterministic payload reinjection

Advent Cybersecurity source audit, 26 November 2026. The primary source is [Gambit Security's September field investigation](https://gambit.security/blog-posts/autonomous-ai-agents-online-retailers-25-a-company). This note uses it to distinguish autonomous controller activity from live revision of a resident payload. No model, agent, or malware was run here.

Gambit says its team recovered an operator staging server and compared its logs and AI claims with exfiltrated material and live or scanner-recorded website skimmers. That mixed record is stronger than stylistic AI attribution, although the authors explicitly warn that some controller claims remain unverified. They report 105 attack projects launched from 10–15 September, but only 48 project histories retained for a chart; the other 57 were deleted. The report says at least 27 companies were compromised to varying degrees. These counts have different units and visibility. None is a trial denominator for payload self-revision.

The operation used Strix for discovery, Cairn for exploitation, and Hermes for orchestration, with OpenRouter model access. The human operator gave 1,951 prompts over 260 Hermes sessions, including broad goals and later tactical instructions. The report's $25.46 mean is an **operator-side cost review over 101 completed scans**, not a measured cost of one endpoint-resident model, one successful compromise, or a Drexel two-revision attempt. The authors also report more than 600,000 card records from two victims and separately verified skimmer installations. Those outcomes establish substantial external-agent operational capability, not in-implant code change.

One website case is especially easy to misread. When an application redeploy restored a clean checkout bundle, the attacker left a cron job that checked the bundle's size every two minutes and **reappended the skimmer** if it was gone. This is a deterministic persistence/reinfection routine acting on website files across deployments. Gambit does not tie each reinsertion to a new model response, a changed executable version, one continuing process, or a separate remote-control result after each insertion. Its distinct skimmer paths and variants also span different victims and installation methods.

The case informs a paper distinction: a controller can adapt an intrusion while a hosted payload or foothold changes or is repaired; these events must not be counted as one resident payload revising its own code twice. The source cannot estimate same-process serial reliability, endpoint model resource cost, or detection probability for Drexel.
