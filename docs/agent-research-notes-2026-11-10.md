# Additional evidence audit — 2026-11-10

Research question: Has a public primary source demonstrated **one continuing program applying at least two model-caused payload revisions while independently retaining remote access after each**?

These notes distinguish cumulative offline code changes, attacker-side agent edits during live operations, applied changes within the implant, and verified remote-access continuity. They record findings for reconciliation into the master evidence document. They contain no build procedure or sample links.

## Metric caveat for LLMalMorph

Its reported functionality preservation is **not an end-to-end remote-control test**. The denominator is variants whose AV detection rate fell below the baseline. Preserved behavior is inferred from normalized longest-common-subsequence similarity of original and variant API-call sequences at threshold 0.96, with manual sandbox-report review used to calibrate that threshold. Its HiddenVNC sample scored 75% (VirusTotal) and 68.182% (Hybrid Analysis) on this proxy. These percentages cannot be interpreted as successful C2 reconnection rates. [Methods and Table V](https://arxiv.org/html/2507.09411v2).

## Current synthesis

The strongest new sources establish **cumulative offline variants** (LLMalMorph) and **field-observed attacker-side agent revision of deployed artifacts** (Anthropic). Neither publishes the time-aligned process identity, source lineage, model output, applied version, and remote-access checks needed to verify the full one-program multi-revision hypothesis.
